## 💻 Slide 2: Description
* **Heading:** What is GitHub?
* **Bullet Points:**
  * A cloud-based platform designed to store, manage, and track software code.
  * Operates as a global social network for engineers, programmers, and developers.
  * Utilizes the "Git" version control system to let multiple people work on the same codebase simultaneously without conflicts.
* **Visual Checklist:** A clean screenshot of a repository homepage layout.

---

## 💻 Slide 3: Main Features
* **Heading:** Core Functionalities
* **Bullet Points:**
  * **Repositories (Repos):** Secure digital folders used to store a project's files and its entire revision history.
  * **Pull Requests & Code Reviews:** Systems where developers safely propose changes and check code for security bugs before merging.
  * **GitHub Copilot:** A built-in generative AI coding assistant that speeds up coding tasks by up to 55%.
* **Visual Checklist:** Use distinct layout icons for a folder, a branching arrow, and an AI/robot icon.

## 💻 Slide 4: Purpose
* **Heading:** What is it used for & Who uses it?
* **Bullet Points:**
  * Used for secure version control, tracking software issues, and open-source project building.
  * Used by **Professionals** (Software development engineering teams).
  * Used by **Students & Beginners** (To learn programming and display their digital portfolios).
  * Used by **Enterprises** (To safely protect corporate tech assets).
* **Visual Checklist:** Split image showing a student coding and a corporate tech office setting.

## 💻 Slide 5: History / How it was created
* **Heading:** The Origins of GitHub
* **Bullet Points:**
  * Founded by **Tom Preston-Werner, Chris Wanstrath, P. J. Hyett, and Scott Chacon**.
  * Officially launched to the public on **April 10, 2008**, in San Francisco, California.
  * **The "Why":** Built because the founders wanted to turn a complex local tool like Git into a visual, web-based platform that made social coding easy.
* **Visual Checklist:** A timeline graphic highlighting 2008 (Launch) and 2018 (Acquisition by Microsoft for $7.5 Billion).

## 💻 Slide 6: Popularity & Current Success
* **Heading:** GitHub in Numbers
* **Bullet Points:**

  * Top regional communities: United States (28M developers), India (21.9M developers), Brazil (6.89M developers).
